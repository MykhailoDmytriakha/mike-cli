# Проверить дела против правил

```sh
./bin/mike check        # из корня проекта; или `mike check`, если mike в PATH
```

Печатает нарушения (`x …`, правило и строка) в stdout и предупреждения в stderr; выход `3`, если есть хоть одно нарушение. Что проверяет — грамматики README / TODO / JOURNAL / файлов фаз (F0–F13), отпечатки (S1), файлы `.recover.md`, вложенные дела. Каждое нарушение дописывается в `.cases/checks.log` — сырьё для `review`.

Нарушение чинится по `.cases/RULES.md`: README — секция уходит в файл; событие журнала — детали в тело под строкой; фаза без RESULT — дописать, что она дала; `*.recover.md` — внести строки командами `mike` и удалить файл.
