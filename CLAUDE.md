# mike-cli

## Работа
- Вся работа ведётся в `.cases/`. Начни с `./bin/mike` — он печатает, где дело стоит и что дальше; правила — `.cases/RULES.md`.
- README / TODO / JOURNAL дела пишутся только через `./bin/mike` (`mike help` — примеры). Правка руками ловится отпечатком.
- Упёрся — сначала `.howto/` (рецепты, первая строка `when:` — слова беды) и `scripts/`, потом решай сам.

## Код
- Весь код — English целиком: имена, комментарии, docstring, сообщения вывода. Русский — только в описаниях для человека (README, журнал, рецепты).

## Память
- **Ничего не сохранять во внутреннюю auto-memory** (`~/.claude/projects/.../memory/`). Не создавать там файлов, не писать в `MEMORY.md`.
- Всё, что нужно помнить между сессиями, живёт в этом репозитории — в файлах проекта, которые видит любой агент (Claude Code, Codex).
